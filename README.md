# ЛР № 1 — медицинская информационная система (вариант 7)

Учебная база PostgreSQL для учёта пациентов, врачей, приёмов, диагнозов и назначений. Данные вымышлены; названия некоторых диагнозов используются только для демонстрации и не являются клиническим справочником.

## Файлы

- `schema.sql` — семь таблиц, ключи, связи и ограничения.
- `data.sql` — тестовые данные и девять проверок: некорректные `INSERT`/`UPDATE` должны завершиться сообщениями `PASS` без изменения данных.
- `migrations.sql` — место для изменения структуры после дополнительного задания преподавателя. Пока содержит план: конкретное требование ещё не выдано.
- `ER_схема_Obsidian.canvas` — ER-диаграмма с атрибутами, PK, FK и связями; открывается в Obsidian.
- `Шпора ЛР_1.md` — краткая памятка по SQL и нормальным формам для защиты.

## Запуск

Создать пустую базу PostgreSQL и выполнить в ней **целиком**, в указанном порядке:

1. `schema.sql`
2. `data.sql`

В DBeaver следует запускать именно весь скрипт, а не только текущую команду. После загрузки ожидаются 12 пациентов, 8 врачей, 12 приёмов, 7 связей «приём — диагноз» и 4 назначения. В конце `data.sql` должны появиться девять сообщений `PASS`.

## Основные решения

У каждого врача одна специальность; у пациента и врача может быть много приёмов. Связь приёмов и диагнозов M:N вынесена в `appointment_diagnosis` с составным PK `(appointment_id, diagnosis_id)`. Назначения хранятся отдельно: на одном приёме их может быть несколько.

Модель приведена к 3НФ: ячейки содержат отдельные значения; свойства связи «приём — диагноз» зависят от всей пары ключей; название специальности хранится в `specialty`, данные пациента — в `patient`, а название диагноза — в `diagnosis`, без повторения в связанных таблицах.

Целостность обеспечивают `NOT NULL`, `UNIQUE`, `CHECK`, внешние ключи с `ON DELETE RESTRICT` и частичный уникальный индекс, допускающий не более одного основного диагноза на приём. Время начала приёма уникально отдельно для врача и пациента; проверка пересечения **интервалов** приёмов в этой учебной модели не реализована.
